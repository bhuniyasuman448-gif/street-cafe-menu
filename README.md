# ☕ Street Cafe – Digital QR Menu

A modern and responsive digital menu website for Street Cafe.

Customers can scan a QR code placed on the table and instantly view the cafe menu on their mobile phone.

## 🍽️ Menu

### Sandwiches
- Veg Sandwich — ₹40
- Paneer Sandwich — ₹60
- Chicken Sandwich — ₹60

### Cold Coffee
- Cold Coffee Small — ₹40
- Cold Coffee Large — ₹60
